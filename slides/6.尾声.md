# 尾声：PM形式化背后的哲学选择

写下这篇文章的时候，我和一个老师刚开完了一场会；repo当前的星数是5颗星。于是我想，我可以趁这个时机，让这个repo变得更加个性化一些。

从一个计算机专业的视角来看，当下是AI时代。网上对AI的讨论如日中天，因为AI可以替代太多事情了。有些人确实相信了这一点，于是用纯粹的vibe coding做出产品拿去卖。很快，产品就崩溃了，而且修理起来极其困难。

有些人因此开始缅怀一类叫做“古典程序员”的人。实际上，哪怕至今，古典程序员仍然非常好找，只是绝大部分人都被自身的生涯推动着前进，无暇回顾往事，更无暇关注愈发膨胀的互联网。我相信绝大多数情况下，但凡人们是真心热爱学科，拥有自己的追思，那么总能以一步一个脚印的方式，开辟一片洞天。

AGI之后，人们的面试再也不考Leetcode；在“内卷”这个词得到广泛的讨论之前，程序员的面试门槛节节升高。在[MongoDB is Web Scale](https://www.youtube.com/watch?v=b2F-DItXtZs)的那个年代，Facebook可能是写个1+1=2就能进入的公司，而Google程序员直至几个月前也仍被Linus诟病为“不会写代码”。从产品的角度来说，尽快做出一个新的社交app是头等大事；而对于具有浪漫情怀的程序员来说，他们更想要慢条斯理地做出一个社交app，在这app下面是修驴蹄、造皮具一般精致的工程艺术，每一步都严丝合缝、干劲利落又无可挑剔；而一套合适的抽象将让这一切如虎添翼——亦或无足轻重。程序员曾是一个时代的黄金职业，是一个时代科技的象征，而这科技之中的科技，似乎便是每一个“下一个时代的编程语言”，又或者是在这些编程语言背后所支撑着的数理理论——其中的一些领域，宣传的时候还免不了“菲尔茨奖得主”的名号。

曾有一段年头，许多人开始青睐Haskell这门语言，并为此到达了狂热的地步；藉由背后“艰深”的范畴论，它仿若是程序员直通数学代数领域的虫洞。新一代学生，不论是代数理论学生还是计算机科班，对各自领域的审视都多了几分理智：至少现在的今日新星是Rust，而有一些数学理论也只是被人称作“网红理论”。在这些表象背后，越来越多人愿意分享自己参与一门学科的所思所得。

网上的争论自始未断：究竟哪一门编程语言更好？为了去支持自己的观点，有些人用A语言写B语言，用B语言写C语言；用范畴语义写C语言；有些人用图形引擎写操作系统，用操作系统写图形引擎；有些人用最新的编程语言[重写项目](https://www.youtube.com/watch?v=i7aQig-wjYA)。有些人闭源了事。

而自始至终，不论是钻研技术，还是用技术去钻研软件，这些想法都是软件工程师所能够产生的想法，却并不能超越软件工程师所能产生的想法。向上，我们想要一款名噪一时的产品；向下，我们又希望能够一展精致紧凑的本领，这些本领又要是“优中选优”的盖棺定论——而“银弹”思维便是如此根植于互联网上，根植于钻研技术的人们的心中。

在我选数学原理作为形式化材料的时刻，我看到的世界是这样子的：更多数人选择去继续壮大类型论中的各种技术细节；AI4Math渐有如日中天之势，而AI4Phil这个概念尚未出现。数学原理所代表的“类型论”是历史的产物，它甚至不是一门类型论，理应没有技术优势，“没有难度可言”。但是我依然选择这个材料，仅能是因为我不相信以现在的技术，数学原理仍不能被形式化。

与此同时，我又尽可能地在网上作出各种调查，力图搞清楚其他学科的氛围：人们看待各种问题、讨论各种问题的风格是什么。计算机的人们希望一门语言能代表编程范式的全面革新。内燃机一开始被发明出来的时候还会漏油，但是现在已经成为了汽车的主流选择，几乎无可挑剔；又要在新能源的浪潮中被逐渐淘汰。因此网上出现了星星点点的声音：去主导内燃机技术的地域，因过多对细化的投入、过少对范式的创新而陷入“技术中等陷阱”。以内燃机为脉络去了解的科技史，让我回顾计算机的人们，感觉他们对科技，乃至对创新的理解，显然要天真得多。

我们可以继续在历史上往前追溯。曾经有一个时代，移动端app大行其道；曾经有一个时代，IBM的IT咨询日赚千金；曾经有一个时代，工业软件是暴利行业；但是在这一切，一切之前，一条听闻在我的脑海中早已“气若游丝”——有那么一个时代俄罗斯程序员名震四方，那个时代的绝大多数大学本科计算机的课程设置被批评“水分太大”，因为学生不学数理逻辑，不学集合论。对于本科的我，这曾一度是让我惋惜的鞭策动力；虽然哪怕现在我也没学好集合论。

而太阳照耀着满月，于是大地灿灿生辉。绝大多数通过中文了解FP、PLT的人，或许多多少少看过某个网红绘声绘色的写下的一系列故事，听闻了一段德克萨斯州Scheme语言的神话，一个大牛对理想的Bidirectional Type Checker的追求（当然这不一定是此大牛的主要希冀和事迹）。网红的文章曾强烈地吸引了当时的我，让我多么期望也能有一段如此的理性的教育和精神翱翔的经历。在我对数学原理进行形式化的时候，我偶尔也顺便翻阅调查相关的工作，调查的过程让我看到了另外一个与前面所说的大牛处于同时代的人物。和老师交流的时候，老师也向我介绍了这个人的更多事迹，让他的形象在我眼中变得更加立体。正像那个网红见证着他的大牛一样，我或许早在不知不觉中以缓慢的速度见证自己的大牛；这些事迹若能娓娓道来，或能让人获得网红一般的声誉。一个天真的学生梦或将迎来终结，而我终于认识到，世界上不为人知的角落里，仅是这种程度的风景，实际上也俯拾皆是。
