# 中文文档
本文档预设读者具有阅读英文的能力，否则无法阅读《数学原理》原文、相关的参考文献以及本项目的英文文档。

本项目使用了较为简单的技术对罗素《数学原理》进行了形式化工作。相较于此项目的完成情况和技术细节，我更希望说一下为啥我会挑这个项目并一直做下去：
1. 《数》有深层的歧义，使得它的形式化成为了一种需要一定程度的主观判断和交流的问题
2. 本项目的发展路数类似于开发游戏：使用的（CG）技术简单，但是这套技术能被用在一个好问题上，并在持续的打磨之下渐入至臻之境，让人们可以新的乃至更为方便的视角去理解它

以当下的AI浪潮，一个本属于顶尖群体的词语突然通过媒体映入大众眼帘：taste。“什么是taste”曾经是一个数理领域的问题，而计算机的版本则是“什么是好技术”。“什么是好技术”本是一个计算机的问题，但是如果将视角放大，“什么是好东西”是一个不局限于专业、领域的问题，它牵涉着很多观念的对立，如理论/实践，科研/企业等。如何定义一样好东西？个人认为，理解这个问题的方式取决于这个问题所处的环境。为此，我希望能推荐一些材料作为不同的环境的案例：
- （微信文）Dream，《我的博导也是干摩托车发动机的，他为什么没干出来？》
- （微信文）刘宅宅闲谈，《时代变了，中文系历史系什么的，确实没太必要专门跑大学去上了》
- （书籍）The Intellectual Life of the British Working Class

现中文网络教人何为科研的内容已逐渐变多，读者亦可自行搜索比对。

本项目实质上是我对上面这一系列问题的追问，是我的一个心结。写这个项目的时候，各种基础的技术问题教我如何理解各种技术的哲学；写这个项目以外的时间，我则逐渐在其它各种我感兴趣的领域中深入发掘。我看到有些人会用最小的代价进行各类试错；我看到有些人会将所有自己踏足的地方做得扎扎实实。各种领域的哲思启发着我，让我受益良多。对于上面“什么才是真正的好东西”，我最大的感触是：有些人可以去为人们的未来做事情，还有些人可以去为人们需要的东西做事情。于是，完成至开始写20章的时候，我所理解的那些道理让我逐步的释怀。我计划在写完了这个章节以后，将时间用在更好的地方上。
