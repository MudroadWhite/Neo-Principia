# 中文文档
本文档预设读者具有阅读英文的能力，否则无法阅读《数学原理》原文、相关的参考文献以及本项目的英文文档。

本项目使用了较为简单的技术对罗素《数学原理》进行了形式化工作。相较于此项目的完成情况和技术细节，我更希望说一下为啥我会挑这个项目并一直做下去：
1. 《数》有深层的歧义，使得它的形式化成为了一种需要一定程度的主观判断和交流的问题
2. 本项目的发展路数类似于开发游戏：使用的（CG）技术简单，但是这套技术能被用在一个好问题上，给人们以新的乃至更为方便的视角去理解它
3. 这个项目本质上是我的一个心结，而它的完成也标志着我逐步的释怀

“什么是好技术”本是一个计算机的问题，但是如果将视角放大，“什么是好东西”是一个不局限于专业、领域的问题，它牵涉着很多观念的对立，如理论/实践，科研/企业等。如何定义一样好东西？个人认为，理解这个问题的方式取决于这个问题所处的环境。为此，我希望能推荐几篇微信文章作为不同的环境的案例：
- Dream，《我的博导也是干摩托车发动机的，他为什么没干出来？》
- 刘宅宅闲谈，《时代变了，中文系历史系什么的，确实没太必要专门跑大学去上了》
